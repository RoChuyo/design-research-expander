# Design Research Expander

Design Research Expander 是一个用于 Codex 的研究辅助 Skill，面向产品设计、工业设计、CMF、交互设计、服务设计和通用设计等领域的早期研究计划整理。它的主要用途是根据用户提供的研究计划书、开题稿或题目设想，辅助完成研究问题梳理、资料线索整理、方向扩展、工作量估计和中文研究资料归档。

本项目不是文献数据库，也不替代研究者的判断。它提供的是一个可复用的研究整理流程，用于提高资料组织、方向比较和计划书改写的效率。

## 主要功能

| 功能 | 说明 |
|---|---|
| 计划书解析 | 从文本中提取研究对象、目标用户、使用场景、研究目的、方法、预期成果和限制条件。 |
| 资料线索整理 | 根据任务需要整理论文、理论、产品案例、竞品、设计奖项、标准和行业资料线索。 |
| 研究方向扩展 | 从用户、场景、材料、技术、系统、文化、可持续和评价方法等维度提出可能方向。 |
| 工作量估计 | 以 S/M/L/XL 等级估算方向的相对工作量，并说明影响因素。 |
| 中文输出 | 默认以中文进行分析和总结，保留必要的论文题名、品牌名、标准名和专有名词。 |
| 资料归档 | 创建中文命名的资料夹、来源库、案例图册、方向矩阵、方法计划和综合报告。 |
| 图片案例管理 | 产品图片文件名包含产品名和特点总结词，并在 Markdown 文档中插入本地图片路径。 |

## 适用场景

- 产品设计研究计划书扩展
- 工业设计毕业设计开题
- CMF 与材料体验研究
- 设计案例和文献综述整理
- 通用设计、老人用品、残障辅助产品方向探索
- 医用器械外观、握持、触觉界面与家用护理产品调研
- 生活产品、桌面产品、交互原型和服务系统的早期方向比较

## 不适用范围与限制

- 不保证自动检索结果完整，正式研究仍需要研究者通过学校数据库、图书馆、Google Scholar、CNKI、ACM、IEEE、ScienceDirect 等渠道复核。
- 不自动判断论文质量，引用前需要人工确认来源、年份、作者、DOI 和上下文。
- 不替代伦理审查、医疗器械法规、人因工程验证或真实用户测试。
- 工作量估计是规划用的相对估计，不等同于项目管理中的精确排期。
- 当涉及医疗、残障、老人、儿童或个人数据时，输出应被视为设计研究建议，而不是专业医疗或法律建议。

## 安装方法

### 方法一：复制 Skill 文件夹

将仓库中的 `skill/design-research-expander` 复制到 Codex skills 目录：

```bash
mkdir -p ~/.codex/skills
cp -R skill/design-research-expander ~/.codex/skills/
```

然后重启 Codex，或新开一个 Codex 线程。

### 方法二：使用安装脚本

```bash
./安装到Codex.sh
```

## 使用示例

### 分析研究计划书

```text
使用 $design-research-expander 分析以下产品设计研究计划书：
【粘贴计划书】
```

### 强化研究目的和意义

```text
使用 $design-research-expander 分析我的研究计划书，重点指出研究意义和研究目的哪里不够明确，并给出可直接改写进计划书的中文版本。
```

### 收集案例并归档

```text
使用 $design-research-expander 为我的产品设计课题收集文献、产品案例和设计奖项案例，并生成中文资料夹归档。
```

### 比较研究方向

```text
使用 $design-research-expander 根据我的研究方向生成 8 个可能发展方向，估计工作量、风险和第一步行动。
```

## 默认输出结构

除非用户指定其他格式，Skill 通常按以下结构输出：

1. `对计划书的理解`
2. `可用资料线索`
3. `可发展的研究方向`
4. `优先级建议`
5. `整段启发性汇总`

当需要保存到本地时，默认采用以下分类：

```text
00_原始资料
01_资料来源
02_案例图册
03_方向矩阵
04_方法计划
05_计划书改写
06_综合报告
07_图片资料
08_中间文件
99_归档
```

## 示例研究主题：陶土表面痕迹转译

该 Skill 可用于分析材料表面如何转译为产品设计语言。例如，在“陶土表面痕迹转译为产品 CMF 表面语言”的研究中，可以将材料特征拆解为：

| 陶土特征 | 可能的设计转译 |
|---|---|
| 裂纹 | 边界、方向、透光路径、时间感 |
| 凹凸 | 握持、防滑、触觉反馈、手指停靠 |
| 颗粒感 | 摩擦差异、区域识别、自然质感 |
| 压痕 | 按压提示、定位点、手作痕迹 |
| 孔隙 | 加湿、蒸发、冷却、香气扩散 |
| 哑光温润 | 降低设备冷感，提升生活化和亲近感 |

这类分析可以进一步整理为案例图册、研究方向矩阵、方法计划和计划书改写文本。
