# Design Research Expander

一个面向**产品设计研究计划书**的 Codex Skill：输入研究计划书、开题稿或题目设想后，帮助你自动扩展研究方向、收集论文与产品案例、估算工作量，并用中文生成可继续写作和归档的研究资料。

它特别适合产品设计、工业设计、CMF、交互设计、服务设计、人机交互、通用设计、毕业设计和研究生开题阶段。

## 为什么做这个 Skill

很多设计研究计划书的问题并不是“没有想法”，而是想法还没有被整理成清楚的研究问题：意义不够强、目的不够明确、案例和文献证据不足、工作量无法判断、最后的方向也容易散。这个 Skill 的目标是把一份初步计划书转化为一个更像研究项目的资料包：

- 帮你找到相关论文、理论、产品案例和设计奖项案例。
- 帮你把研究方向从“灵感”扩展成可验证的问题。
- 帮你估计每个方向的工作量和风险。
- 帮你用中文输出结构化分析，而不是英文资料的直接堆叠。
- 帮你把文档、图片和来源按中文文件名归档。

## 功能亮点

| 功能 | 说明 |
|---|---|
| 计划书理解 | 提取设计对象、用户、场景、研究目标、方法和限制条件。 |
| 文献与案例收集 | 同时关注论文、理论、现有产品、竞品、设计奖项、标准和行业资料。 |
| 产品设计方向扩展 | 从用户、场景、材料、技术、系统、文化、可持续和评价方法发散方向。 |
| 工作量估计 | 为每个方向估算 S/M/L/XL 工作量，并说明原因。 |
| 中文输出 | 默认用中文表达，保留必要的论文题名、品牌名和专有名词。 |
| 中文命名归档 | 自动倾向使用中文文件名和分类文件夹管理研究资料。 |
| 图片案例图册 | 产品图片文件名会包含产品特点总结词，并在 Markdown 中插入本地图片路径。 |
| 启发性总结 | 输出最后一整段连续中文总结，帮助你获得研究灵感。 |

## 安装方法

### 方法一：复制 Skill 文件夹

将仓库中的 `skill/design-research-expander` 复制到 Codex skills 目录：

```bash
mkdir -p ~/.codex/skills
cp -R skill/design-research-expander ~/.codex/skills/
```

然后重启 Codex，或新开一个 Codex 线程。

### 方法二：使用安装脚本

```bash
./安装到Codex.sh
```

## 使用方式

在 Codex 中输入：

```text
使用 $design-research-expander 分析以下产品设计研究计划书：
【粘贴你的计划书】
```

也可以指定任务：

```text
使用 $design-research-expander 分析我的研究计划书，重点帮我强化研究意义和研究目的，并给出可直接改写进计划书的中文段落。
```

```text
使用 $design-research-expander 为我的产品设计课题收集文献、现有产品案例和设计奖项案例，并生成中文资料夹归档。
```

```text
使用 $design-research-expander 根据我的研究方向生成 8 个可能发展方向，估计工作量、风险和第一步行动。
```

## 输出结构

默认输出包括：

1. `对计划书的理解`
2. `可用资料线索`
3. `可发展的研究方向`
4. `优先级建议`
5. `整段启发性汇总`

如果需要保存为文件，它会优先使用类似这样的中文分类：

```text
00_原始资料
01_资料来源
02_案例图册
03_方向矩阵
04_方法计划
05_计划书改写
06_综合报告
07_图片资料
08_中间文件
99_归档
```

## 适合的研究主题

- 产品设计研究计划书扩展
- 工业设计毕业设计开题
- CMF 与材料体验研究
- 陶土、陶瓷、木材、金属、织物等材料转译
- 通用设计、老人用品、残障辅助产品
- 医用器械外观与触觉界面
- 生活产品、桌面产品、交互原型、服务系统
- 设计案例与文献综述整理

## 示例：陶土表面痕迹研究

这个 Skill 曾用于整理一个关于“陶土表面痕迹转译为产品 CMF 表面语言”的研究方向。它帮助拆解出：

- 裂纹可以转译为边界、方向和透光路径。
- 凹凸和颗粒感可以转译为握持、防滑和触觉识别。
- 压痕可以转译为按压提示和定位点。
- 孔隙可以转译为加湿、蒸发、冷却和香气扩散。
- 哑光温润感可以降低医疗设备和护理产品的冰冷感。

这类分析可以继续发展为产品原型、案例图册、研究方向矩阵和计划书改写稿。
