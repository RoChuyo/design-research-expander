# 示例提示词

## 研究计划书扩展

```text
使用 $design-research-expander 分析以下产品设计研究计划书，帮我扩展可能研究方向、收集相关论文和产品案例，并估计每个方向的工作量。

【粘贴计划书】
```

## 强化研究意义和目的

```text
使用 $design-research-expander 分析我的研究计划书，重点指出研究意义和研究目的哪里不够强，并给出可直接改写进计划书的中文版本。
```

## 创建中文归档资料夹

```text
使用 $design-research-expander 根据我的课题创建中文研究资料夹，资料包括来源库、案例图册、方向矩阵、方法计划和综合报告。
```

## 产品案例图册

```text
使用 $design-research-expander 为我的课题收集 10 个产品案例，包括图片、来源链接、核心信息、与研究的关联和可借鉴点。图片文件名请包含产品特点总结词，并在 Markdown 中插入本地图片路径。
```

## Markdown 与 Notion 同步

```text
使用 $design-research-expander 将已有研究资料汇总成一份中文 Markdown 报告，要求嵌入图片，并在 Notion 中创建同内容副本。
```

## 工作量估计

```text
使用 $design-research-expander 根据我的研究计划生成 8 个可能方向，并为每个方向估计 S/M/L/XL 工作量、原因、风险和第一步行动。
```
